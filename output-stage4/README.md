# Paquete científico del terreno original

Ver ../docs/stages/04-georreferenciacion-ciencia.md para métodos, reproducción, cobertura y límites. terrain_metadata.json vincula original, matrices, CRS y transformaciones; georeference-validation.json y remote-source-check.json contienen comprobaciones. manifest.json inventaría salidas.

scientific_elevation.bin y scientific_elevation.tif son alturas del producto sinexagerar. visual_elevation.bin conserva elGLB. No mezclarambas para pendientes. NoData=NaN/máscara0.

# HiRISE

Metadata record only (`dataset.json`). No HiRISE product or pixel is committed.

Reference sources:

- HiRISE: <https://www.uahirise.org/>
- PDS Planetary Image Atlas: <https://pds-imaging.jpl.nasa.gov/>

HiRISE products are not all orthorectified or controlled in the same way. Any
future pair must record the product level, map projection, ground sample
distance, emission/incidence/phase angles and whether the images share a
controlled cartographic reference. The NASA Mars Trek WMTS mosaics already used
by MARS OPS do not expose a complete multitemporal observation archive.

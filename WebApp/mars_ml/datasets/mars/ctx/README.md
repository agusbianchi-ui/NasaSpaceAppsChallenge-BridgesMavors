# CTX

Reference notes only. The selected CTX records live in `../ctx_multitemporal/dataset.json`; no pixels are committed.

Reference sources:

- MRO CTX: <https://www.msss.asu.edu/data/>
- PDS Geosciences Node: <https://pds-geosciences.wustl.edu/>

CTX provides broader coverage than HiRISE at a coarser ground sample distance.
Future work must verify product level, projection, effective resolution and
acquisition geometry before comparing scenes. Do not infer metre-scale motion
from a resolution that does not support it.
